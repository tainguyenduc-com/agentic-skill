# Blazor + Tailwind
- Small components with clear parameters; call APIs through a client/service, never touch persistence.
- Semantic HTML, labels, keyboard focus, responsive layout; every data screen has loading, empty and error states.
- Form validation matches the backend validator; show ProblemDetails.
- Tailwind utilities; extract repeated markup into components; no second UI framework.
- `.razor` files are only partly indexed by CodeGraph (see code-navigation): Grep for `@inject` and component usage.
- Reference examples: `.claude/skills/blazor-tailwind/examples.md` if it exists.
